# Nb.1 取扱説明書

Rev. 1.0 / 2026-08-06

---

## 1. はじめに

本製品は12ポジションのプログラマブル入力デバイスです。
各ポジションには **Cherry MX 互換スイッチ**または**ロータリーエンコーダ**の
どちらかが実装されています。

配列は3行 × 4列。左上を「1番」として、以下のように数えます。

```
       列1    列2    列3    列4
行1  [  1 ] [  2 ] [  3 ] [  4 ]
行2  [  5 ] [  6 ] [  7 ] [  8 ]
行3  [  9 ] [ 10 ] [ 11 ] [ 12 ]
```

---

## 2. 接続

USB Type-C ケーブルで PC に接続するだけです。ドライバのインストールは
不要で、標準的な USB キーボードとして認識されます。

Windows / macOS / Linux / ChromeOS に対応します。

**注意:** ケーブルは必ず**データ通信対応**のものを使ってください。
充電専用ケーブルでは認識されません。

---

## 3. 出荷時の割り当て

### 3.1 レイヤー構成

本製品には2つのレイヤーがあります。

| レイヤー | 名称 | 呼び出し方 |
|---|---|---|
| 0 | BASE | 通常状態 |
| 1 | FN | ポジション9を押している間 |

### 3.2 BASE レイヤー(通常時)

**押したとき**

| ポジション | 機能 |
|---|---|
| 1 | ミュート切り替え |
| 2 | 前のトラック |
| 3 | 再生 / 一時停止 |
| 4 | 次のトラック |
| 5 | テンキー 7 |
| 6 | テンキー 8 |
| 7 | テンキー 9 |
| 8 | ÷ |
| 9 | **FN レイヤー(押している間)** |
| 10 | テンキー 0 |
| 11 | . |
| 12 | Enter |

**回したとき(エンコーダ実装ポジション)**

| ポジション | 左回り | 右回り |
|---|---|---|
| 1 | 音量ダウン | 音量アップ |
| 2 | 前のトラック | 次のトラック |
| 3 | Page Down | Page Up |
| 4 | ← | → |
| 5 | ホイール下 | ホイール上 |
| 6 | ↑ | ↓ |
| 7 | マウス左 | マウス右 |
| 8 | Shift+Tab | Tab |
| 9 | − | = |
| 10 | [ | ] |
| 11 | , | . |
| 12 | 画面輝度ダウン | 画面輝度アップ |

### 3.3 FN レイヤー(ポジション9を押しながら)

| ポジション | 機能 |
|---|---|
| 1 | **書き込みモードに入る** |
| 2〜4 | F13 / F14 / F15 |
| 5〜8 | F16 / F17 / F18 / F19 |
| 10〜12 | F20 / F21 / F22 |

F13〜F22 は通常のキーボードには無いキーなので、
アプリのショートカット割り当てに便利です。

## 4. インジケータ LED

基板上の赤色 LED は、出荷時は **Num Lock 連動**です。
Num Lock がオンのときに点灯します。

レイヤー表示など、他の用途に変更することもできます(6章参照)。

---

## 5. 書き込みモード(ファームウェア更新)

ファームウェアを書き換えるには、書き込みモード(DFU モード)に入ります。
方法は2つあります。

### 方法1:キー操作(通常はこちら)

**ポジション9を押しながら、ポジション1を押す。**

即座に書き込みモードに入り、PC からは「STM32 BOOTLOADER」として
認識されます。キーボードとしては一時的に反応しなくなります。

### 方法2:BOOT0 ボタン(ファームが壊れたとき)

1. USB ケーブルを抜く
2. 基板上の **BOOT0 ボタンを押したまま**
3. USB ケーブルを挿す
4. ボタンを離す

ファームウェアが起動しない状態でも、この方法なら必ず書き込みモードに入れます。

### 書き込みコマンド

```bash
qmk flash -kb nb1 -km default
```

または

```bash
dfu-util -a 0 -d 0483:df11 -s 0x08000000:leave -D nb1_default.bin
```

書き込みが終わると自動的に再起動し、通常のキーボードに戻ります。

## 6. カスタマイズ

### 6.1 準備

QMK の開発環境を用意し、本製品のファイル一式を配置します。

```
qmk_firmware/keyboards/nb1/
├── keyboard.json
├── config.h
├── board.h
├── mcuconf.h
└── keymaps/default/
    ├── keymap.c
    └── rules.mk
```

ビルドは以下のコマンドです。

```bash
qmk compile -kb nb1 -km default
```

### 6.2 キーの割り当てを変える

`keymap.c` の `keymaps` 配列を編集します。左上から右下へ、
行ごとに並んでいます。

```c
[_BASE] = LAYOUT_3x4(
    KC_MUTE, KC_MPRV, KC_MPLY, KC_MNXT,   // ポジション 1〜4
    KC_P7,   KC_P8,   KC_P9,   KC_PSLS,   // ポジション 5〜8
    MO(_FN), KC_P0,   KC_PDOT, KC_PENT    // ポジション 9〜12
),
```

使えるキーコードの一覧は QMK 公式ドキュメントを参照してください。

### 6.3 エンコーダの割り当てを変える

`keymap.c` の `encoder_map` を編集します。
各行が `{ 左回り, 右回り }` です。

```c
{ KC_VOLD, KC_VOLU },  //  0  ポジション1
```

### 6.4 回転方向が逆のとき

`keyboard.json` の該当エンコーダの `pin_a` と `pin_b` を入れ替えます。

```json
{ "pin_a": "C8",  "pin_b": "C9"  }
```

### 6.5 1ノッチで2回動く / 半分しか動かないとき

`config.h` の以下の行のコメントを外して調整します。

```c
#define ENCODER_RESOLUTION 4
```

1ノッチで2回反応するなら値を大きく(4 → 8)、
半分しか反応しないなら小さく(4 → 2)します。

### 6.6 LED の動作を変える

`keymap.c` の以下の部分を書き換えます。

```c
bool led_update_user(led_t led_state) {
    writePin(INDICATOR_LED, led_state.num_lock);
    return false;
}
```

レイヤー表示にしたい場合は、`led_update_user` の中身を
`return false;` だけにして、`layer_state_set_user` を使います
(`keymap.c` にコメントで例を記載しています)。

## 7. トラブルシューティング

### PC に認識されない

まず**データ通信対応のケーブル**か確認してください。充電専用ケーブルが
原因のことが最も多いです。

それでも認識されない場合、BOOT0 ボタンを押しながら接続して
「STM32 BOOTLOADER」が見えるか確認します。

- **見える** → ファームウェアの問題。書き込み直してください
- **見えない** → ハードウェアの問題。組み立て手順書を参照してください

### キーが1つも反応しない(エンコーダは動く)

**J16 と J17 を繋ぐケーブルを確認してください。**
マトリクスの行3本すべてがこのケーブルを通っているため、
外れていると全キーが無反応になります。

エンコーダは MCU 直結なので、ケーブルが無くても動作します。
この症状が出たら、ほぼ確実にケーブルが原因です。

### キーの位置がずれている

J16-J17 のケーブルが逆向き(1-3、3-1)に繋がっています。
ケーブルを正しく繋ぎ直してください(1-1、2-2、3-3 のストレート)。

### 特定のキーだけ反応しない

そのポジションの以下を確認してください。

- Kailh ホットスワップソケットのはんだ付け
- スイッチのピンが曲がっていないか
- 対応するダイオードの向きとはんだ付け

### エンコーダが反応しない / 飛ぶ

- A / B / C パッドのはんだ付けを確認
- 反応が飛ぶ場合は `ENCODER_RESOLUTION` を調整(6.5節)
- 逆回転する場合は `pin_a` / `pin_b` を入れ替え(6.4節)

### 書き込み後に動かなくなった

BOOT0 ボタンを押しながら USB を挿せば、必ず書き込みモードに入れます。
正常に動いていたファームウェアを書き戻してください。

## 8. 取り扱い上の注意

- 動作温度範囲は 0〜50 ℃ を目安としてください
  (発振子の定格が −10〜60 ℃ です)
- 基板がむき出しの状態では、金属面の上に直接置かないでください
- USB ケーブルの抜き差しは、コネクタ部分を持って行ってください
- 分解・改造による故障は自己責任となります
